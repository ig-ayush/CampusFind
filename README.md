# Campus Lost & Found

A clean, responsive Lost & Found web app designed for college students.

Built for the **Codédex Back 2 School Monthly Challenge**.

## Features

- Browse lost and found reports
- Search items
- Filter by status and category
- Report a lost or found item
- Save reports with browser LocalStorage
- Item detail modal
- Contact reporter
- Dashboard statistics
- Recently reported items
- Light/dark mode
- Responsive mobile layout
- Toast notifications
- Keyboard-friendly item cards

## Technology

- HTML
- CSS
- Vanilla JavaScript
- LocalStorage

## Run locally

No build tools are required.

Simply open `index.html` in a browser.

For a better local development experience, use VS Code with the Live Server extension.

## Project idea

Students often use different WhatsApp groups or notice boards when they lose something on campus. CampusFind provides one simple place to report and discover lost or found belongings.
